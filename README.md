# 楚河棋室

中國象棋人機對弈網頁。單一 HTML 檔，不需安裝、不需後端，直接用瀏覽器開啟即可。

## 功能

- **五個電腦等級**：一級入門、二級初學、三級棋友、四級高手、五級大師。走出第一步前可以更換。
- **落子無悔**：沒有悔棋，重新整理頁面也會回到原局面。
- **棋譜紀錄**：中文記譜（炮二平五／馬8進7），可一鍵複製；完成的對局保存在瀏覽器中（最近 30 局）。
- **覆盤分析**：終局後自動逐手分析，標出疑問手、錯著、敗著，指出「問題從哪一手開始」，並畫出形勢曲線、在棋盤上用箭頭比較實戰與建議著法。
- **棋子動畫**：砲高拋旋轉、吃子爆炸；馬分兩段躍起；車直線衝鋒；象沉重落地；被吃的棋子會被打飛。
- **音效與配樂**：全部以 Web Audio 即時合成；五聲音階古箏風格配樂。音效、配樂可分別關閉，並可調整音量。

## 使用

- 線上版（GitHub Pages）：開啟 Pages 後的網址為 `https://willychang-jimu.github.io/xiangqi-game/`
- 本機：直接用瀏覽器開啟 `index.html`。

## 規則簡化

長將不判負；同一局面重複三次或連續 120 手未吃子判和。

## 技術

- 走子產生器經 perft 驗證（起始局面 1–4 層：44 / 1920 / 79666 / 3290240）。
- 搜尋：Alpha-Beta + PVS、置換表、殺手著法、歷史啟發、靜態搜尋與將軍延伸，在 Web Worker 中執行，不卡畫面。
